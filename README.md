# The Cumulative Quranic Lexicon

An interactive, cumulative reading of Qur'anic vocabulary beginning with Juz 'Amma and moving from Surah An-Nas backward.

## Run locally

This is a static site. Open `index.html` directly, or serve the folder with any static HTTP server.

```bash
npx serve .
```

## Deploy

Import the GitHub repository into Vercel with the framework preset set to **Other**. No build command or environment variables are required.

## Source status

The interface labels working corpus counts and estimates that still require verification. Those truth-boundary labels should remain visible until the underlying data has been checked.
